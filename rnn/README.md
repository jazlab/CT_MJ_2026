# RNN models

- `models/`: one folder per model (see the table in the top-level README), one sub-folder per seed.
- `vendored/src/rnn/`: model, task, loader and plotting code.
- `figures.py`: entry points used by the figure scripts.
- `training/`: training scripts, one per model (`train_<model>.sh`; set `REPO` at the top).
